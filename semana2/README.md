# Laboratorio 02 - Carrito de Compras en Kotlin
**Nombre:** Magaly Rosales Porras
## Descripción 
El siguiente programa simula el funcionaamineto de un carrito de compras. Lo cual permite agregar productos con ciertos atributos, permite calcular el subtotal, el IGV, el total a pagar, descuentos generados, busqueda, eliminación asi con ciertas funciones que se establecieron.
## Funciones implementadas
- calcularSubtotal
- calcularIGV
- calcularTotal
- mostrarDetalle
- calcularDescuento
- buscarProducto (reto adicional)
- removeIf para eliminar producto (reto adicional)

## Respuesta:
- val: se usa en nombre y precio porque son datos fijos que no deben cambiar una vez creado el producto. Por ejemplo, si ya está publicado el producto, no se puede cambiar su nombre ni modificar su precio.
- var: se usa en cantidad porque ese valor sí puede cambiar el cliente agrega o quita unidades del mismo producto.
